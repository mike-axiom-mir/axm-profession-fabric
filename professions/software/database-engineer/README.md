# Database Engineer

Status: **EXPERIMENTAL**

This isolated Profession Package reconstructs bounded Database Engineer work: schemas, constraints, transactions, query behavior, migrations, durability, backup/restore, and database-operational evidence.

Primary seed: the currently published ISO/IEC 9075:2023 SQL family, including the 2026 corrigendum where applicable. A language standard seeds bounded knowledge; it does not define the whole profession.

Structural validity is not professional competence.
