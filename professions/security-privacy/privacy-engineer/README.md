# Privacy Engineer

Status: **EXPERIMENTAL / HIGH-STAKES**

This package reconstructs bounded privacy-engineering work: data-flow/inventory evidence, privacy-risk analysis, minimization, purpose/retention/deletion requirements, privacy-by-design review, and technical handoffs.

NIST Privacy Framework 1.0 is used as a final reference seed. NIST Privacy Framework 1.1 is still an Initial Public Draft / coming-soon update and is recorded as draft context, not silently treated as final.

This package does **not** provide legal advice or certify regulatory compliance.
