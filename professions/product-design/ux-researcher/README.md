# UX Researcher

Status: **EXPERIMENTAL**

This isolated Profession Package reconstructs bounded UX Research work: research questions, study design, participant/sample boundaries, interviews/usability/contextual methods, evidence capture, synthesis, limitations, and research handoffs.

ISO 9241-210:2019 is a human-centred-design seed, not a complete research-methods standard. Research findings remain bounded to method/sample/context and never become universal user truth by wording.
