# Product Designer

Status: **EXPERIMENTAL**

This package reconstructs bounded product-design work: user/task flows, interaction models, information hierarchy, states, prototypes/specification, usability/accessibility-aware design handoffs, and evidence-driven iteration.

Primary seed: ISO 9241-210:2019, reconfirmed in 2025 as current, for human-centred design principles/activities. It does not replace UX Research, Accessibility, Visual Design, or Product Management.
