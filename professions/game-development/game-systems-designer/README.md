# Game Systems Designer — EXPERIMENTAL

Reconstructs bounded design work for game rules, resources, scoring, progression, difficulty/pressure, spawn logic, state transitions, win/loss conditions, and meaningful tradeoffs.

Seed evidence: Ghost Studio Systems work on relay decay/solvability and the terminal completion-vs-blackout ambiguity. The latter is important: Systems detected and modeled the contradiction but deferred the core win/loss philosophy decision instead of silently claiming authority.

Broader economies, progression/metagame, multiplayer balance, live-service systems, content pacing, and human balance/fun validation remain incomplete.
