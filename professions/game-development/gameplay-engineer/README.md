# Gameplay Engineer — EXPERIMENTAL

Reconstructs the engineering work behind player controls, movement/action response, input-device parity, interaction timing, player-state transitions, collision response, retry/recovery behavior, and the measurable mechanics that produce moment-to-moment play.

Seed evidence: AXM Ghost Studio Gameplay work on gamepad parity, radial deadzones, neutral-after-retry behavior, collision-aware movement cost, and cross-role system consequences.

This is not a claim that gameplay feel is solved or that a machine can replace human play judgment. Physical-device feel, broader genres, animation/physics-heavy games, networking, accessibility hardware, and production-scale engines remain incomplete evidence areas.
