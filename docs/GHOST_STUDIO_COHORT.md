# Ghost Studio profession-reconstruction cohort

AXM Ghost Studio provides unusually rich observed specialist behavior, but its seven studio roles are **institution roles**, not automatically one-to-one human professions.

Profession Fabric uses Ghost Studio as experimental source evidence, then asks whether the observed work belongs to a real bounded profession, multiple professions, or an institution-level coordination role.

## Direct profession matches in this cohort

- Software QA / Playtest
- Software Integration / Release Engineer
- Gameplay Engineer
- Game Systems Designer
- World / Encounter Designer

## Roles that require decomposition or broader mapping

- **Experience / Art / Audio Director** bundles several human disciplines. Profession Fabric should reconstruct visual/art direction, sound design/audio, UX/readability/accessibility, and related specialisms separately before optionally defining an institution-level combined role.
- **Game Director** mixes creative direction, product identity, milestone/scope governance, and cross-discipline coordination. It is useful source evidence for future Creative Director / Game Director and institution-role research, but should not be copied wholesale into a generic profession body without decomposition.

## Rule

Observed agent-role success is evidence about work structure, not proof that the role boundary is a valid human profession boundary.
