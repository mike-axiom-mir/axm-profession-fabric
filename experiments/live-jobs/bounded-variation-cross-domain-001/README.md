## Shared procedure under test

The profession-level layer verifies only the repeated evidence shell:

1. exact source repository + revision;
2. exact base/source and family digests;
3. explicit mutation authority and immutable contract;
4. fresh source-owned family execution;
5. at least three retained materially different outputs;
6. candidate/output digest identity;
7. retained bounded HOLD/failure control;
8. explicit truth boundary and ownership handoff.

A harness negative control deliberately duplicates one retained output identity and must be rejected.
